# The Gabriel Foundation (Gabrial Foundation)

**Empowering Women, Ending Abuse, & Rebuilding Safe Futures**

The Gabriel Foundation is a non-profit organization dedicated to protecting women and girls from violence and all forms of abuse. We offer three core lifelines:

1. **1-on-1 Female Mentorship & Sisterhood Support Circles**
2. **Confidential Trauma Counseling & Therapy**
3. **Life Reset & Emergency Housing Assistance ("Reset Up")**

---

## 🚀 Tech Stack

* **Framework:** Next.js 15 (App Router)
* **Library:** React 19
* **Language:** TypeScript
* **Styling:** CSS Modules & Custom Vanilla CSS Tokens
* **Icons:** Lucide React

---

## 🛠️ Getting Started Locally

```bash
# Install dependencies
npm install

# Run dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application in your browser.
